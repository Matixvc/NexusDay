# NexusDay — Dirección visual Nex (U9.2)

## Principios

- Base de grafito y carbón: fondos `#111315` y `#171A1D`; las ilustraciones no sustituyen texto ni controles nativos.
- Violeta suave como firma visual; menta y cian existentes solo como señales tecnológicas puntuales.
- Luz volumétrica contenida, transparencias reales en adornos aislados y geometría orgánica de baja frecuencia.
- Ilustración editorial 3D mate, superficies limpias y contraste suficiente para convivir con texto claro.
- Dejar zonas de descanso para la interfaz. Los fondos son atmósfera de baja prominencia; las ilustraciones de estado tienen un foco único.
- Blanco y Oscuro reutilizan recursos neutros con contraste comprobable. Nex recibe el énfasis violeta sin cambiar tokens ni acentos persistidos.

## Evitar

Texto o números dentro de las imágenes, mockups de interfaz, marcas, personas, exceso de neón, circuitos minúsculos, ruido, partículas densas, fondos recargados y formas decorativas sin área libre para contenido.
